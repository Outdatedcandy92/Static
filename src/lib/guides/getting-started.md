Before starting, you have two pathways you can follow:

1. Design your own custom project related to FM radio
2. Follow the guide and design a radio with parts provided in the kit

If you're new to hardware, I would highly recommend following the guide to make your first project. If you're more experienced or want to experiment with stuff, you can make things like FM transmitter dongles, FM receiver dongles, or random cool stuff like an FM alarm clock, a band scanner, or a radio with an RDS text display. An example of a custom project would be this one: [https://github.com/Outdatedcandy92/FM-Transmitter](https://github.com/Outdatedcandy92/FM-Transmitter)

**Kit pathway**

If you're using the kit, you can use the following parts:

- Xiao RP2040
- RDA5807
- TDA2822NBD
- 1W Speakers
- Potentiometers
- Passives
- detailed list launching soon

Footprints and symbols for these can be found on [github.com/Outdatedcandy92/Static-KiCAD-Library](https://github.com/Outdatedcandy92/Static-KiCAD-Library)

## Custom Pathway

For the custom pathway, you're free to use whatever components you want, but there are tiers based on the quality of your submission.

### Tier 1: $50
Simple projects like a basic FM receiver or speakers.

![A CAD render of a simple FM radio enclosure, an example of a Tier 1 custom project](/guides/media/fusion360-radio-kit.png)

### Tier 2: $100
Complex and polished projects, like this FM radio transmitter: [https://github.com/Outdatedcandy92/FM-Transmitter](https://github.com/Outdatedcandy92/FM-Transmitter)

![An FM transmitter dongle PCB, an example of a Tier 2 custom project](/guides/media/fm-transmitter-dongle-pcb.jpg)

---

If you're unsure what tier your project would fall into, just drop a message in [#static](https://hackclub.enterprise.slack.com/archives/C0BSCTE57KL)!

## Time Tracking

You have the option to either use Lapse or journal your progress. I would suggest using Lapse if you don't like writing. But if you're interested in journalling, please read the Journalling guide. Low quality journal entries will not be accepted as a valid submission.
